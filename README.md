# Addit AI 🚀

AI-powered creator assistant that transforms videos into summaries, chapters, captions, and optimized content.

## Features (Planned)

- 🎥 Video Upload
- 🎙 Speech-to-Text
- 📝 AI Summary
- 🕒 Chapter Generation
- 🏷 SEO Tags
- 🎯 YouTube Title Generator
- 💬 Video Chat (RAG)
- ✂ Smart Video Editing

## Tech Stack

- Python
- FastAPI
- Streamlit
- Google Gemini API
- Whisper
- OpenCV
- MoviePy
- FFmpeg

🚧 Currently under active development.
